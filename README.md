# Campus Connect

Campus Connect is a web app that helps students find faculty members inside the college campus. Students can search for a faculty member and see which room or cabin to go to, so they don't waste time looking around.

## Features
- Separate Student and Faculty views
- Search faculty by name or department
- Filter by department (Computer Science, Electronics, Administration, Mechanical)
- Shows each faculty member's room or cabin location
- Shows a status note when a faculty member's location may be outdated

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase (database)
- Lucide React (icons)
- Built with the help of Bolt.new (AI tool)
  
## How to Run Locally
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open the local link shown in the terminal
